# Introduction to Probability & Statistics with Python

A beginner-friendly static teaching website with short Python-terminal exercises and a synthetic CoffeeTruck.csv dataset.

## Local preview
Open `index.html` in a browser.

## Publish
Push `index.html` and `CoffeeTruck.csv` to a GitHub repository. In Settings → Pages, choose Deploy from a branch, `main`, `/(root)`.

## Python requirements
`python -m pip install pandas matplotlib numpy`

The supplied CSV is synthetic and is not the original classroom CoffeeTruck dataset.
