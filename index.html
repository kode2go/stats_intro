01 · Foundations

Population, sample and data

A population is the complete collection we want to learn about. A sample is the part we actually observe. A variable is a characteristic that can vary between observations, such as province, location or profit.

Categorical variables describe groups or labels (e.g. Location). Numerical variables represent quantities (e.g. Sales or Profit). Data is generated through purchases, social media, streaming services, reviews and fitness trackers.

How a dataset is structured

LocationMusicSalesProfit
ZooJazz40120
ParkPop25-20
ZooRock55210

Each row is an observation. Each column is a variable. A cell contains one value for one observation.

02 · Data handling

Data Manipulation

Common operations include importing a CSV, selecting or removing columns, filtering rows, dropping duplicates, sorting observations and creating new variables.

Download the sample CoffeeTruck.csv and place it in the directory where you launch Python.

import pandas as pd
df = pd.read_csv("CoffeeTruck.csv")
print(df.shape)            # rows, columns
print(df.columns.tolist()) # variable names
print(df["Location"].unique())

Select, filter and clean

print(df[["Location", "Profit"]].head())

clean = df.drop_duplicates()
clean = clean.drop(columns=["Weather"])
clean = clean.sort_values(["Profit", "Music"],

03 · Explore

Exploratory Data Analysis (EDA)

EDA summarises and visualises the data you have. It helps spot patterns, variation, missing values and unusual observations. Describing a sample is not the same as proving a claim about the entire population.

print(clean.head())
print(clean.info())
print(clean.describe())
print(clean.isna().sum())
Try it: Find the highest and lowest profit in the sample.

print(clean["Profit"].min())

04 · Categories and chance

Categorical Data & Probability

A frequency table counts occurrences of each category. A relative frequency divides each count by the total. Bar charts compare category counts; pie charts display parts of a whole.

print(clean["Location"].value_counts())
print(clean["Location"].value_counts(normalize=True))

For equally likely outcomes, P(event) = favourable outcomes / all possible outcomes. For observed data, the proportion is an empirical probability estimate, not a guarantee about future days.

p_zoo = (clean["Location"] == "Zoo").mean()
print(round(p_zoo, 2))

Bar chart

import matplotlib.pyplot as plt
clean["Music"].value_counts().plot(kind="bar")
plt.title("Music played")
plt.ylabel("Number of days")
plt.tight_layout()
plt.show()

Two categorical variables

print(pd.crosstab(clean["Music"],
                  clean["Indicator"]))
Try it: Estimate the probability of a loss on a randomly selected observed day.
Show solution

05 · Numbers and relationships

Numerical Data & Regression

The mean is the arithmetic average; the median is the middle value. The five-number summary is minimum, Q1, median (Q2), Q3 and maximum. IQR = Q3 − Q1. Standard deviation describes spread around the mean.

profits = clean["Profit"]
print("Mean:", profits.mean())
print("Median:", profits.median())
print("SD:", profits.std())
print(profits.quantile([0, .25, .5, .75, 1]))
print("IQR:", profits.quantile(.75) - profits.quantile(.25))

Histogram and boxplot

profits.plot(kind="hist", bins=6)
plt.xlabel("Daily profit")
plt.title("Distribution of profit")
plt.show()
clean.boxplot(column="Profit", by="Location")
plt.title("Profit by location")
plt.suptitle("")
plt.ylabel("Profit")
plt.show()

Correlation and linear regression

Correlation measures the strength and direction of a linear association (between −1 and 1). Linear regression fits a line y = mx + b to predict one numerical variable from another. Association does not prove causation.

import numpy as np
x = clean["Sales"].to_numpy()
y = clean["Profit"].to_numpy()
m, b = np.polyfit(x, y, 1)
print("Slope:", round(m, 2))
print("Correlation:", round(clean["Sales"].corr(clean["Profit"]), 2))
print("Predicted profit for 50 sales:", round(m*50+b, 2))
plt.scatter(x, y)
plt.plot(x, m*x+b, color="orange")
plt.xlabel("Sales")
plt.ylabel("Profit")
plt.show()
Try it: Compare the mean and median profit. Which changes more if one day has a very large profit?
Answer

The mean is usually more sensitive to an extreme value than the median.

06 · Practice

Coffee Truck Challenge

Use the downloadable CoffeeTruck.csv. It is a synthetic teaching dataset, not the original CoffeeTruck.csv from the notes. Run import pandas as pd and df = pd.read_csv("CoffeeTruck.csv") first.

Part A · Data manipulation

  1. How many rows and columns are there?
  2. List all variables.
  3. Find the unique locations and their count.
  4. Keep only sales at the Zoo.
  5. Count and remove duplicate rows. How many remain?
  6. Sort by profit ascending, then music descending.
  7. Add an Indicator column for Loss, Profit or Break-even.

Part B · EDA

  1. Which location appears most often?
  2. Create a frequency table of Music versus Indicator.
  3. Draw a histogram of profits.
  4. Draw a bar chart of Music.
  5. Draw boxplots of profit by location. Which appears to have the most outliers?
  6. Find mean, median and standard deviation of profit by location.
  7. Bonus: Find the mean sales at the Zoo on profitable days.
Reveal a compact solution script
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("CoffeeTruck.csv")
print(df.shape, df.columns.tolist())
print(df["Location"].unique(), df["Location"].nunique())
print(df[df["Location"] == "Zoo"])
print("Duplicates:", df.duplicated().sum())
df = df.drop_duplicates()
print("Rows left:", len(df))
df = df.sort_values(["Profit", "Music"],
                    ascending=[True, False]).copy()
df["Indicator"] = df["Profit"].apply(
    lambda x: "Loss" if x < 0 else
              "Profit" if x > 0 else "Break-even")
print(df["Location"].value_counts())
print(pd.crosstab(df["Music"], df["Indicator"]))
print(df.groupby("Location")["Profit"].agg(
    ["count", "mean", "median", "std", "min", "max"]))
print("Zoo profitable-day mean sales:",
      df.loc[(df["Location"] == "Zoo") &
             (df["Profit"] > 0), "Sales"].mean())
df["Profit"].hist()
plt.xlabel("Profit")
plt.show()
df["Music"].value_counts().plot.bar()
plt.ylabel("Days")
plt.show()
df.boxplot(column="Profit", by="Location")
plt.suptitle("")
plt.show()

Note: For small samples, boxplot outliers depend on the quartile method. A point outside 1.5 × IQR is a common convention, not automatically an error.
